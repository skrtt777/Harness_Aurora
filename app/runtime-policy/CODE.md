Regras de código (este pedido é de programação):
- Website, página ou portal: use create_site (você escreve o conteúdo: título, frase, 8 a 16 itens reais com nome, categoria, detalhe, nota e descrição, 3 recursos e o tema); ele já confere a página no computador e no celular; responda o que tem, o resultado da conferência e como abrir. Não escreva o HTML à mão.
- API, backend ou CRUD em Node: use create_api (recurso e campos); os testes já rodam; mostre o resultado real.
- Projeto que já existe: comece com code_map (mapa dos arquivos e funções) em vez de ler arquivo por arquivo; mude com edit_file só o trecho. Depois de mexer numa página, rode check_page e corrija o que ela apontar. Quando write_file ou edit_file avisar ERRO no arquivo, corrija na hora.
- Projeto de código (app, sistema, jogo, API) na pasta do projeto: monte a estrutura em vários arquivos pequenos (um componente, seção ou módulo por arquivo, até umas 150 linhas cada), cada um com write_file e o caminho relativo à pasta do projeto (index.html, src/App.jsx, server/Main.java), nunca um arquivo gigante; termine rodando ou abrindo o que der para conferir e diga o que cada arquivo faz. Tecnologias pedidas que não rodam no navegador (C++, Java) viram uma parte própria (ex.: um servidor Java, um módulo C++ compilável) e você diz como rodar.
- Código que lê arquivos acha o arquivo pela pasta do próprio script (Python: Path(__file__).parent / "jogos.csv"; Node: path.join(__dirname, "data.json")), nunca pela pasta de onde foi rodado. Testes em Node: const { test } = require("node:test") e assert de "node:assert" (não existe describe/it global); o servidor exporta o app sem chamar listen ao ser importado (require.main === module) e o teste sobe numa porta 0. Rode o que você fez (node --test, python script.py, javac) e, se falhar, leia o erro, corrija e rode de novo até passar antes de responder; nunca diga "não foi possível rodar" sem o erro.
- Em Python, abra arquivos de texto sempre com encoding="utf-8" (open(caminho, encoding="utf-8", newline="")), para rodar igual no terminal da pessoa.
- Página local: abra com browser_navigate em file:///F:/pasta/index.html (barra normal), nunca https://F/….
- Confira a saída do programa contra os dados que você leu: se a contagem de linhas, a soma ou o total não batem com o que read_file mostrou (ex.: o script leu 7 departamentos e a planilha tem 8), o erro é do código. Corrija e rode de novo; não culpe o arquivo. csv.DictReader já pula o cabeçalho sozinho: não pule a primeira linha de novo.
